# 大学生实用GPTplugins
根据自己的学习需求制作的一些ChatGPT插件

这里收录了一些我根据自己的学习需求制作的插件，希望把实用的学习流程分享给更多人。

## 软件基础
obsidian，Anki

## 插件列表

| 插件 | 作用 |
| --- | --- |
| **English Vocabulary Studio** | 将英语词表图片整理成适用于 Obsidian 和 Anki 的学习资料 |
| **Lecture Notes Studio** | 将课程 PPT 或 PDF 整理成忠实于课件内容的 Obsidian 笔记 |

## English Vocabulary Studio

上传一张或多张英语词表图片，生成四类学习资料：

- **英语词汇总表**：包含单词、词性、中文释义和单词笔记
- **例句与分组短文**：按词汇分组整理例句、英文短文和中文翻译
- **情境短文合集**：通过主题短文复习词汇
- **Anki 单词卡片**：以 TSV 格式生成，可导入 Anki

生成的文件会打包为 `listXX.zip`，方便导入 Obsidian。

## Lecture Notes Studio

上传大学课程的 PPT、PPTX 或 PDF 课件，生成整理后的 Obsidian 笔记包：

- **课程知识笔记**：提取并整理课件中的主要知识点
- **知识点速览**：快速查看本节课的内容框架
- **例题与习题解析**：单独整理课件中的例题和习题；课件没有答案时，补充答案与解析
- **教学图片**：保留课件中的相关图片，并在笔记中引用

知识笔记以用户上传的课件为内容来源，重点是提取、整理和归纳课件内容。
